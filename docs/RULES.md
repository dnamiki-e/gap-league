# ゲームのルール

Gap League には**独立した2つの競技**がある。順位予想と得点予想で、
**スコアは合算しない**（別々のランキングになる）。

参加の単位は「シーズン × リーグ」。同じ年でもプレミアとラ・リーガは別の勝負になる。

---

## 1. 順位予想 — 差が小さいほど上位

締切までに、そのリーグの全チームを1位から最下位まで並べる。
シーズン終了後、予想順位と実順位のズレを合計したものがスコアになる。

### スコア計算

チームごとに次を求め、全チーム分を足す（実装: [lib/scoring.ts](../lib/scoring.ts)）。

| 条件 | 加点 |
|---|---|
| 予想順位 = 実順位（完全一致） | **-2 点** |
| それ以外 | **順位差の絶対値 × 1** |

**合計が小さいほど上位。** 完全一致でマイナスが入るのは、
「大きく外さない安全策」より「当てにいく」ほうが報われるようにするため。

例（4チームリーグ）:

| チーム | 予想 | 実際 | 差 | 加点 |
|---|---|---|---|---|
| A | 1 | 1 | 0 | **-2** |
| B | 2 | 4 | 2 | +2 |
| C | 3 | 2 | 1 | +1 |
| D | 4 | 3 | 1 | +1 |
| | | | | **合計 +2** |

### 点数の変更

完全一致点（既定 -2）と順位差の倍率（既定 1）は、**管理画面からサイト単位で変更できる**。
変更後の同期でスコアが再計算される。

---

## 2. 得点予想 — 指名した3人の合計得点が多いほど上位

締切までに選手を**最大3人**指名する。何点取るかは予想しない。
シーズン中、その3人が実際に挙げた得点の合計がそのままスコアになる。

**合計得点が多いほど上位。** 順位予想とは別のランキングで、点数は混ざらない。

### 指名のルール

| ルール | 理由 |
|---|---|
| 1シーズンにつき最大3人 | — |
| 同じ選手を複数枠に入れられない | — |
| **前年の得点上位10人は指名できない** | 全員が同じ顔ぶれを選んで横並びになるのを避けるため。前年データが取れないシーズン（初回など）は制限なし |
| GK は候補に出ない | 現実的に得点が起きないため |

指名は各クラブの選手一覧から選ぶ。移籍で上流が同じ選手を移籍前後の両クラブに
載せることがあるため、**指名した時に見えていたクラブ**を記録して表示する
（後から同期でクラブ表示が変わらないようにするため）。

### 集計

上流の得点ランキングは「1点以上の全得点者」を返す。
そこに載っていない選手は**取りこぼしではなく 0 点と確定**できるので、そのまま 0 として合計する。

得点予想の一覧には、現在の得点王（同得点なら全員）も並べて表示する。
これは実データなので予想のネタバレにはならない。

### 未入力の扱い

得点予想を入れていない参加者も一覧に行として出る（入力済みの後ろに名前順）。
行を消すと、本人が「自分が入れていない」ことに気づけないため。

## 3. 締切

順位予想と得点予想で**締切を別に設定できる**。

| 締切 | 対象 |
|---|---|
| `predictionDeadline` | 順位予想。開幕直前に置くのが普通 |
| `scorerDeadline` | 得点予想。**未設定なら順位予想と同じ扱い** |

得点予想の締切を後ろに置けるようにしてあるのは、
「順位はもう締めたが、得点予想はもう少し受け付ける」という運用ができるようにするため。

締切を過ぎると、その予想は編集できなくなる。

---

## 4. 見えるもの・見えないもの（ネタバレ防止）

自分の予想はいつでも見える。**他人の予想・順位・スコア**の見え方はシーズンの状態で変わる
（実装: [lib/season-visibility.ts](../lib/season-visibility.ts)）。

| 状態 | 条件 | 他人の予想・順位・スコア |
|---|---|---|
| 締切前 | 順位予想の締切前 | **見えない**（先に見て真似できてしまうため） |
| 進行中 | 締切後・残り6節以上 | 見える |
| 終盤 | 締切後・**残り5節以下** | **見えない**（優勝争いのネタバレを避けるため） |
| 開示済み | 管理者が「結果を開示」を押した | 見える |
| 確定 | シーズンをロックした（アーカイブ） | 見える |

- 残り節数は「全チームの最大消化試合数」から計算する。
  総節数はリーグごとに固定（20チーム = 38節、18チーム = 34節）。
- **「結果を開示」は最終節が全チーム完了するまで押せない。**
- 得点予想の一覧は、この制限の対象外（締切前でも表示する）。
  指名選手の実得点は現実の記録であって、順位予想のネタバレにはならないため。

---

## 5. ランキングの見方

| 画面 | 内容 |
|---|---|
| 現在のランキング | 進行中シーズンの暫定順位。同期のたびに更新される |
| アーカイブ | 確定済みシーズンの結果 |
| 予想比較表 | チーム別 × 人別に、誰が何位と予想したかを一覧で見る |
| 統計 | 的中率、順位の推移、相性（予想の似ている人）など |

進行中シーズンのスコアは「その時点の順位で計算した暫定値」であって、最終結果ではない。
