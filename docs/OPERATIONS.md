# 運用ガイド

シーズンを立てて、参加者を集めて、1年回して、確定させるまで。
すべて管理画面（`/admin`）から操作する。

---

## シーズンを1年回す流れ

```
シーズン作成 → 参加者を招待 → 予想入力（締切まで）
   → 定期同期でスコア更新 → 最終節後に結果を開示 → ロックしてアーカイブへ
```

### 1. シーズンを作る

「管理 > シーズン」で作成する。指定するのは4つ。

| 項目 | 例 | 備考 |
|---|---|---|
| リーグ | プレミアリーグ (`PL`) | 有効リーグは「管理 > 設定」で選ぶ |
| シーズン年 | `2025` | 開始年。2025-26 シーズンなら 2025 |
| 表示名 | `25-26` | 画面に出る名前 |
| 順位予想の締切 | 開幕日の直前 | |

作成したら**「同期」を実行**する。チーム一覧が入り、参加者が予想を組めるようになる。

> 上流にまだそのシーズンが無いと「まだ公開されていません」と警告が出る。
> エラーではないので、開幕が近づいてから同期し直せばよい。

### 2. 得点予想の締切を分ける（任意）

得点予想の締切は順位予想より後ろに置ける。設定しなければ順位予想と同じ。
詳細は [docs/RULES.md](RULES.md)。

### 3. 参加者を招待する

「管理 > ユーザー」でメールアドレスを入れて発行すると、**招待リンク**が出る。
これを本人に配る。有効期限は **7日**。

参加者は招待リンクを開いて、パスワード・表示名・推しクラブを設定すればログインできる。

Google 運用の場合は、アドレスを登録しておけばその Google アカウントでそのまま入れる
（招待リンクを使わなくてよい）。

### 4. 定期同期を仕込む

順位表とスコアは同期のたびに更新される。手動でも回せるが、cron に任せるのが普通。

**同梱スクリプトを使う場合:**

```bash
# .env に CRON_SECRET を設定してから
crontab -e
```

```cron
10 3 * * * /path/to/gap-league/scripts/cron-sync.sh >> /var/log/gap-sync.log 2>&1
```

スクリプトは `.env.local` → `.env` の順に `CRON_SECRET` と `GAP_URL` を探す。
`GAP_URL` の既定は `http://localhost:3020`。サブパス配信なら
`GAP_URL=http://localhost:3020/gap` のように基底パスまで含める。

**直接叩く場合:**

```bash
curl -X POST -H "Authorization: Bearer $CRON_SECRET" \
  http://localhost:3020/api/cron/sync
```

- `CRON_SECRET` が未設定だと **503**（＝自動同期は無効）。
- 合言葉が違えば **401**。
- 対象は「有効かつ未ロック」のシーズンのみ。**確定済みシーズンは同期されない**。

**頻度の目安は1日1回**。上流は 10リクエスト/分しか許さず、
1シーズンあたり2リクエスト使う。5リーグ運用なら1回の同期で 10 リクエストになるので、
短い間隔で回すと制限に当たる（アプリ側で間隔を空けるので失敗はしにくいが、
そのぶん同期に時間がかかる）。

### 5. 同期で何が起きるか

1. チーム一覧を取り込む（`Team` / `SeasonTeam`）
2. 順位表を取り込む（`Standing`）
3. その時点の順位をスナップショットとして残す（`StandingSnapshot` — 順位推移グラフの元データ）
4. **全参加者のスコアを再計算する**（`Score`）

一部が失敗しても他は続行し、結果に警告・エラーとして返る。

### 6. 結果を開示する

残り5節を切ると、ネタバレ防止のため他人の順位・予想が自動で隠れる。

**最終節が全チーム完了すると**「結果を開示」ボタンが押せるようになる。
押すと全員に結果が見えるようになる（`resultsRevealed`）。

読み上げ会や発表の場を設けるなら、そこまで押さないでおけばよい。

### 7. シーズンを確定する

「ロック」するとアーカイブ扱いになる。

- 自動同期の対象から外れる（上流のデータが変わっても結果が動かない）
- ランキングのアーカイブに並ぶ

## サイト設定

「管理 > 設定」で変更できる。

| 項目 | 既定 |
|---|---|
| サイト名 | Gap League |
| 完全一致点 | -2 |
| 順位差の倍率 | 1 |
| 有効リーグ | PL / PD / SA / BL1 / FL1 |

スコアの点数を変えた場合、**次の同期で全シーズンのスコアが再計算される**。
シーズン途中で変えると順位が入れ替わるので、開幕前に決めておくのが無難。

認証の設定は「管理 > 認証設定」（別画面）。

## ユーザー管理

### 無効化と削除

- **無効化**（`isActive=false`）: ログインできなくなる。予想とスコアは残る。
  Google ログインからも入れない。
- **削除**: 次の場合は止まる。
  - 自分自身（管理者が自分をロックアウトするのを防ぐ）
  - 最後の管理者
  - 予想・スコアを持つユーザー → **確認のうえ強制削除すれば消せるが、
    ランキングの過去データからも消える**

過去の記録を残したいなら、削除ではなく無効化を選ぶ。

### 管理者を増やす

「管理 > ユーザー」で管理者フラグを付ける。
Google 運用なら `ADMIN_EMAILS` に足して入り直してもよい。

## バックアップ

DB だけ取っておけば復旧できる（予想・スコア・ユーザーはすべて PostgreSQL の中）。

```bash
pg_dump -Fc gap_league > gap_league_$(date +%Y%m%d).dump
```

戻すとき:

```bash
pg_restore -d gap_league --clean gap_league_20260401.dump
```

**シーズン確定の直前・直後**は必ず取ること。
順位表は上流から取り直せるが、予想は取り直せない。
